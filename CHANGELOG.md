## 2026-08-06

### PR #5 · `a2b1db9` — Компактная сетка «Услуги»
Убраны пустоты бенто-раскладки: featured-карточка растягивалась на 2 ряда (735px) при контенте на треть высоты. Теперь все 6 карточек одинаковые (3×2), высота по контенту, уменьшены заголовки/отступы/иконки, тёмная акцент-карточка сохранена. Версия кэш-бастера CSS поднята до `?v=11`.
Файлы: `assets/v2-feedback-01.css`, `assets/config.js`, `CLAUDE.md`

### PR #4 · `0a8b8d0` — Луч радара ведёт переключение узлов
Луч стал источником истины автопилота: JS ведёт его через requestAnimationFrame (оборот 20с вместо 6с), узел и карточка деталей активируются ровно в момент прохода луча через позицию узла (0/90/180/270°). Полоска прогресса привязана к углу луча (`--ap-progress`). Hover — луч замирает; клик — автопилот выключается, луч гаснет (`is-user-controlled`).
Файлы: `assets/app.js`, `assets/styles.css`, `assets/v2-0.css`, `CLAUDE.md`

### PR #3 · `f1a1100` — Автопилот блока «Система»
Узлы диаграммы переключаются сами каждые 5с вместе с карточкой деталей, полоска прогресса на активном узле. Пауза при hover и вне вьюпорта (IntersectionObserver), остановка навсегда по клику, поддержка prefers-reduced-motion. Удалён скрытый дублирующий автоплей из `v2-motion.js` (конфликтовал, не давал остановить переключение).
Файлы: `assets/app.js`, `assets/styles.css`, `assets/v2-motion.js`, `CLAUDE.md`
